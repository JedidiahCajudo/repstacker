## What It Does

The ultimate upgrade from a paper lifting journal.
The most beautiful way to track your 3 x 8-12 reps.

Rails 8.1  
Stimulus.js  
SQLite3

## AI

Used to learn/review Stimulus and Rails, but all coded by hand.

## Setup
```
git clone https://github.com/JedidiahCajudo/repstacker.git
bundle install
rails db:migrate
rails server
```
